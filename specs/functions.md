# 函数

本页说明参数、调用、返回、闭包与函数值，对应主规范 §9、§17.14–17.16。[状态与阶段含义](README.md#如何读矩阵)适用于下表；语义分析 API 当前未提供，正文中的静态检查属于 CLI 编译管线。

## 解析入口

- `parseFormalParameterList(ScanResult)` 接受包含圆括号的形参列表。
- `parseFunctionBody(ScanResult)` 接受修饰符和函数体，不含函数名/形参；箭头体与分号空体要包含末尾分号。
- `parseExpression` 接受匿名函数；`parseStatement` 接受局部函数；`parseCompilationUnit` 接受顶层函数、访问器和变量。

所有入口保留写出的类型、元数据、默认表达式、参数分组和函数体，不补入省略类型或默认值，不绑定捕获或检查返回类型。`int Function(int value)` 在形参列表中是名为 Function 的函数形式形参；`int Function(int value) callback` 才是具有函数类型的普通形参。

独立形参入口可保留 `var`/`final`、旧式默认分隔符 `:`、`this.`/`super.` 和 covariant，不能由此判断它们在外围声明是否合法。局部及匿名函数解析拒绝参数上的 var/final/const；CLI 的旧文件兼容规则与之分开。

异步体解析 await、语句/集合 await for；生成器体解析 yield/yield*，拒绝带值 return 和生成器箭头体。嵌套函数独立设置 async/generator 上下文，参数元数据与默认值沿用外层上下文。同步体中 await/yield 可作标识符；同步语句直接以 `await:` 起始当前会诊断，已有标签后的该形式可解析。模式与 switch 已接入函数体解析，但不绑定跳转目标或进行穷尽性分析。

顶层非 external 函数缺实现、external 函数含实现有语法诊断。import/export/library/part/typedef/extension/mixin/external 在相应上下文仍可作函数名；关键字拼写不单独决定它是指令还是声明。

## 参数、默认值与返回

```dart
int add(int value, {int step = 1}) => value + step;

void main() {
  int Function(int, {int step}) operation = add;
  print(operation(2, step: 3)); // 5。
}
```

CLI 检查参数数量、类型、缺失/重复/未知命名参数。命名实参之后再写位置实参要求调用文件版本至少 2.17；普通与常量构造调用都保留源码求值顺序。每个实参的必要类型检查早于后续实参求值，再按位置和公共名绑定。

默认值在**声明处**求值，不查调用方名字。库/成员用声明库作用域，局部函数可用此前可见的外层 const；普通外层变量不能作默认常量。可空或 dynamic 可选参数可隐式默认 null，非空参数需要默认值。标量、常量 List、部分类实例及顶层函数引用可用；List 默认值仍需显式 const。

return 和箭头结果按声明类型检查/转换。可空、dynamic、void 同步块体正常落空返回 null；非空结果函数必须不能正常落空。Never 调用终止正常路径，并保留先行副作用、不求后续实参；不可达源码仍检查名称、类型和 return。void 箭头可保留实际负载，块体仍限制 void 返回表达式。生成式构造器体只能无值 return。

### 形参修饰符与版本

2.12–3.12 的 CLI 普通形参支持 final/var，包括可选、命名、局部和匿名函数；旧式 typedef 和嵌套函数形式参数也支持，两者不影响函数类型身份。final 从入口只读，捕获、复合写和模式赋值也不能重写。3.13 起禁止非声明参数上的这些修饰符；主构造器的字段声明参数不受该旧语法规则影响。const、late、修饰符组合、var 加显式类型均拒绝。

初始化形式参数支持 `this.field`、默认值、显式子类型到字段的转换。私有命名字段形参要求声明库至少 3.12：去掉首个 `_` 得到合法公共名，声明名与公共名都不能和其他形参冲突，包含位置形参。调用使用公共名，调用方旧版本不改变该规则。命名 super 形参也必须用父参数的公共名。

字段/super 形参可写函数形式，省略返回类型为 dynamic。3.13 前可带 final，但不改变字段本身的可写性；`var this.field` 按固定草案拒绝，虽 SDK 3.13.7 CFE/analyzer 接受 3.12 写法。带 final/var 的函数形式（如 `final int callback(int n)`）按 SDK 拒绝；旧版可用 `final int Function(int) callback`。生成式重定向不能带字段或 super 形参，详见[构造与初始化](classes.md#构造与初始化)。

### 协变参数与访问器

实例方法、setter、运算符支持 covariant，含可选/命名、函数形式及已有泛型方法。标记按位置/公共名从所有接口合并继承；允许收窄，但须与每个父声明对应类型可比较，调用形状不变。接口合并先按原函数子类型选择签名，再合并标记，不能借此放松签名合并。

调用按静态签名检查，实际方法体前检查实现参数类型；失败抛 TypeError。方法值的运行时签名把协变参数放宽为 Object?，调用仍检查实际类型；super.method 用父实现签名。由类参数产生的检查不是显式 covariant，不自动授权收窄覆写。

普通 covariant 形参限上述实例位置，主构造器字段声明参数另按 3.13 规则。SDK 3.13.7 CFE 还接受局部/匿名函数、普通/工厂构造、字段形参和 typedef 中的 covariant，dartc 按固定规范与 analyzer 拒绝这些位置。

顶层 getter/setter 可配对或单独存在。3.9 起读结果与写参数类型独立；此前 getter 结果须是 setter 参数子类型，版本取声明库。未注解为 dynamic；setter 结果须省略或别名展开后为 void，且恰有一个必需位置参数。未使用声明也检查这些规则。

## 泛型直接调用

顶层函数、静态和实例方法（含 call）可声明类型参数、上界和值参数。未使用函数仍检查边界、函数体、返回和赋值。参数可用于 List、用户类、可空类型、非泛型函数签名、is/as 和已支持模式，不能用作常量类型实参；构造器和访问器不能声明自有类型参数。

```dart
T first<T>(List<T> values) => values[0];

void main() {
  print(first<int>(<int>[2]));
  print(first(<int>[3]));
}
```

显式调用检查数量与代入后的上界；省略实参时使用上下文、普通实参和带类型回调约束，无约束时实例化到界。返回上下文与参数上下文独立，print 的 Object? 参数也可参与向下推断。

dynamic 实参不能通过对象实际类型帮助推断；无法静态分解其复合形状时不产生内部约束。解出类型后仍在下个实参求值前检查实际值。SDK 3.13.7 某些隐式调用漏检 dynamic 持有的 List/函数实参，dartc 仍保留该检查，与 SDK 显式类型实参调用一致。

泛型类中再声明类型参数的实例方法、泛型局部/匿名函数、泛型函数值与提取、泛型函数类型、一般泛型父接口界限推断及 `T & S` 提升未支持。泛型 main 仅限无值参数且默认类型实参满足边界；类型参数作为公开 Type 值未提供。

### 回调水平推断

从调用库 2.18 起，泛型函数、方法和生成式构造可从其他实参推断直接函数字面量的省略参数。回调按类型依赖分阶段，循环依赖同阶段；同阶段共用进入时的上下文，阶段结束后固定解。可选、命名及括号内直接字面量同样适用，条件表达式等间接函数值不自动延后。此前版本仍同阶段推断。

普通实参先按源码顺序求值及检查，直接函数字面量随后分析/构造；非泛型、显式泛型、构造和具体函数值调用也允许回调捕获被其他实参初始化的变量。无约束参数用 schema 最大闭包：未知为 Object?，嵌套函数参数方向取 Never，不自动取 dynamic。部分标准库和 dynamic 调用尚不支持此推断。

### 基于界限的推断

从调用库 3.7 起，在向下、水平和最终求解阶段组合已有下界与声明上界。例如 X 的下界是 List<int>，且 `X extends List<Y>`，可继续为 Y 生成 int 约束。覆盖嵌套 List、可空界限、函数结果/参数逆变及多级界限链；普通泛型调用、普通/const 构造和类别名共用规则。

按类型参数声明顺序求解，前阶段固定的解不重新选择。部分求解仅使用已知的约束解，最终求解可处理未知部分；无可分解下界时不读取运行时值补约束。已处理参数不因后续界限回头重解，`<Y, X extends List<Y>>` 与相反顺序可能不同。界限不会额外增加回调依赖边。完整 F-bound、泛型父接口与其余约束求解仍缺。

## 局部函数与匿名函数

同步非泛型局部函数支持自递归、块内遮蔽、只读名字，以及全部已支持参数形状。声明前引用不退回全局，前向互递归拒绝。匿名函数支持同步箭头/块体，省略参数取期望签名，无上下文时取 dynamic；命名参数按公共名称而非顺序匹配。

省略的局部/匿名返回类型从本函数 return 及正常完成性推断，死代码 return 也参与，子函数 return 不参与。无 return 且可落空取 Null，不能正常完成取 Never；结果只控制最终转换，不反向改变字面量实际类型。局部递归先以 dynamic 推断，与 SDK 3.13.5 一致，固定推断 Draft 则描述 inference failure。顶层省略结果仍为 dynamic。

## 词法捕获

闭包支持外层持续读写、共享变量、多层逃逸、自递归及显式/隐式 this。不同工厂调用保留独立绑定，同一作用域重复读取局部函数保留身份。构造初始化器的闭包能捕获参数，不能借闭包读取尚不可用的实例。

for 声明变量每轮独立，更新作用于下一轮绑定；for-in 声明变量也逐轮独立，使用外部变量则仍共享。捕获继承声明点赋值事实，子函数写入不确立外层赋值；非 late 捕获 final 不允许在子函数赋值。被闭包写入的绑定不提升，未显式写入的捕获可保留外围提升。

泛型函数、方法及泛型类构造/成员内的**非泛型**闭包可捕获外层类型参数、普通变量和 this。签名在创建时按实际实参形成，即使只用类型参数、没有值捕获也保留类型环境。自身声明类型参数的闭包、异步捕获及完整闭包流分析仍缺。

## 函数值

仅**可执行文件**支持顶层函数、静态方法、绑定实例方法、局部和匿名函数的存储、传参、返回、typed List 与具体非泛型签名调用/`.call`；object/static/dylib 不支持 Dart 函数值。非泛型构造器值见[类](classes.md#构造器函数值)。

方法提取只求一次接收者并持续持有它；相同对象的同一方法、运行时函数类型相同则相等，不承诺 repeated tear-off 的 identical。协变可使 super.method 和 this.method 运行时类型不同；super 选父具体实现，仍绑定原对象。普通闭包按自身身份比较，无捕获局部对象可按声明共享，但不能依赖跨调用分配策略。

顶层函数、静态方法引用可为常量；实例方法、局部函数和匿名表达式不是常量，即使处于未执行常量分支也检查资格。泛型类的方法提取、部分标准库方法和 Function.hashCode 等继承 API 仍缺。

调用只传显式实参，目标补默认值，不能从静态函数类型猜默认值；省略与显式 null 不同。参数逆变、结果协变、位置区间、命名集合和 required 约束共同决定结构子类型，静态和运行时检查采用同一规则。[实例 getter 的调用顺序](expressions.md#调用与求值顺序)另有括号边界及 SDK 差异。

## 可调用对象

已知非空类的实例 call 方法可通过 `object(...)` 调用，支持继承 call 及方法体内 super(...)。字段、getter、静态成员叫 call 不使对象本身可调用；extension 调用未支持。

赋值、传参、返回、List 单元素和 for-in 变量的函数类型上下文可隐式提取 call，包括具体非泛型签名、Function 及可空形式。Object、dynamic 和无上下文推断仍保留原对象；对象本身不是 Function，显式 as 和 dynamic 检查转换不提取。可空对象不能借可空函数目标提取，spread 不逐元素提取。

条件、??、级联、空断言先确定整体类型，再提取。实例函数字段/getter 的直接调用先求实参再读取，括号包住成员则先读取。SDK 3.13.7 CFE 允许未选中常量分支中的隐式提取、const 构造器普通调用时的提取；真正活跃常量求值仍报错。dartc 采用该边界，analyzer 在这些位置可能直接报告非常量错误。

## `int.parse` 与外部调用

`int.parse(String source)` 当前只支持省略 radix，拒绝多余/命名 source、未知名、类型实参及不兼容实参，未使用函数也检查；实参只求一次。接受 Unicode 首尾空白、正负号、十进制、0x/0X。十进制和负十六进制限有符号 64 位，正十六进制允许完整位模式，`0xffffffffffffffff` 为 -1。非法或超范围输入抛 FormatException，保留 source、非空 message 及可用 offset；文案和 offset 不保证与 SDK 相同。显式 radix 和静态方法值未支持。

一般 external 链接、NoSuchMethodError 路径仍缺；普通 Dart 函数对象不能自动变成 FFI 指针。原生导出另见[FFI](types.md#ffi-类型与原生导出声明)。
