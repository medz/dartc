# 类及相关声明

本页说明类、成员、构造器、枚举与元数据，对应主规范 §10–§14、§16。[状态与阶段含义](README.md#如何读矩阵)适用于下表；语义分析 API 当前未提供，正文的静态规则属于 CLI 编译管线。

## 类与成员解析

`parseCompilationUnit` 解析类、mixin、类类型别名、enum、具名/无名 extension、extension type 及其成员，保留元数据、修饰符、类型参数、extends/with/implements/on、源码顺序和分号/大括号体。不自动生成隐式父类、字段、构造器或访问器。

构造语法包括传统形式、const/factory、命名与简写、主构造器参数、this 初始化体、字段/assert/super 初始化及 this/factory 重定向。parser 有部分修饰符和体形式检查，但不查字段绑定、继承、成员冲突、表示类型资格或参数类型。`factory<T>(T value)` 保留为名叫 factory 的泛型方法，不是工厂构造器。

以下示例处于 CLI 已支持的普通类与 const 构造子集：

```dart
class Point {
  final int x;
  final int y;
  const Point(this.x, this.y);
  int sum() => x + y;
}

void main() {
  const point = Point(2, 3);
  print(point.sum()); // 5。
}
```

## 成员、接口与继承

CLI 按声明身份解析非泛型 extends/implements 和别名，检查重复接口、环及别名边界；直接表示自身类型参数的别名不能作接口，Function 不能作类名。extends 继承实现和字段存储，implements 只引入签名，不继承方法体或存储。子类同名字段仍有独立存储，下划线私有成员按声明库区分。

具体类必须声明或继承兼容实现，未使用类也检查。方法调用按实际对象选择实现，默认参数由实际实现补入；super 从词法父类查找具体实现，忽略抽象声明，保留原 this，闭包也能捕获该接收者。抽象声明不会遮蔽已有具体实现。Object 默认 toString 可满足接口，其他默认成员和完整内建接口仍缺。

覆写检查参数形状、参数逆变、结果协变和泛型边界。组合接口签名选择最具体且满足其他候选的声明，同等候选按接口顺序选择；无组合签名时需足够显式的兼容覆写，不把失败推断退成 dynamic。协变标记合并规则见[函数](functions.md#协变参数与访问器)。

getter、setter、方法分别查找。只覆写一侧访问器不丢弃另一侧；可写字段或显式 setter 可实现写接口。setter 须恰有一个必需位置参数，结果省略或展开后为 void；未注解访问器可从父签名推断，否则为 dynamic。字段推断优先用组合读写类型，可写字段两侧须同型，仅读字段取 getter 结果。无接口约束和声明初始化器则为 dynamic，不从构造器赋值反推。其余初始化器推断子集见[类型](types.md#空安全推断与流分析)。

abstract 字段不分配存储或要求构造初始化，而提供无体 getter 及可选 setter。支持多变量及 covariant 可写字段；拒绝初始化器与 late/static/const/external 组合。元数据关联访问器，协变传给 setter；未初始化 late final 也有 setter。完整外部字段及 mixin 规则仍缺。

静态成员只能按类/类别名限定或类内作用域使用，不被子类继承、不经实例选择。静态体没有 this，不能用类类型参数或隐式实例成员；静态字段惰性初始化，不参与实例构造。绑定保持前缀、别名、part 私有性；非泛型类的非泛型静态方法可作常量函数引用。

成员冲突在声明处检查：方法不能与访问器冲突，可写字段不能再配同名显式访问器；final 实例/静态字段与 const 静态字段可配显式 setter。静态声明不能与本类实例成员、同名构造后缀或已绑定 Object 实例接口名冲突，继承签名也参与检查。一般 dynamic 查找、Invocation/noSuchMethod 转发未支持。

### 用户运算符与相等

支持二元 `+ - * / ~/ % < > <= >= << >> >>> & | ^`、一元 `-`/`~`、`[]`/`[]=`。参数数目固定且只能是必需位置参数，不能 static 或自带类型参数；`[]=` 返回类型须展开为 void，`!`/`!=` 不可定义。非空类接收者、类上界参数、super 运算及索引赋值沿用方法分派；super 索引可简单/复合/??= 赋值和增减，绕过子类覆写，读写分别选择父具体实现。

operator == 未支持。已有标量值相等、对象引用身份和常量规范化身份；活跃常量相等还要求 primitive equality，覆写 hashCode 的类不能用于一般活跃常量相等，与 null 比较除外。

## 构造与初始化

只有**完全未声明构造器**的类才获得默认无参构造。类名、用户类别名和命名后缀按实际声明选择构造；别名不创造新构造器或常量身份，私有后缀按库检查。`.new` 是未命名构造器的同一身份，声明和调用均要求至少 2.15；构造名不进入普通成员作用域，可与实例方法同名。

非重定向生成式构造按以下顺序执行：

1. 按字段声明顺序求值声明初始化器。
2. 按参数顺序执行字段形参初始化。
3. 按源码顺序执行显式初始化列表。
4. 在同一对象上执行父构造链，成功后进入本类构造体。

列表只初始化本类直接字段，final 初始化不经同名 setter；检查缺失、重复、类型和未使用声明。显式 super 调用必须唯一且在列表末尾，实参按源码顺序求值。体内只能无值 return；assert initializer 仍未实现。

初始化列表能读字段/super 形参的声明名，其局部值为 final，名字不进入构造体。普通参数在列表与体共享绑定，列表中的合法赋值对后续可见。初始化 RHS 及其闭包不能读 this 或隐式实例成员。

生成式 `this(...)`、`this.name(...)`、`this.new(...)` 重定向共用同一对象，仅最终目标执行字段初始化与体，每级独立绑定参数和默认值。不能同时有字段/super 形参、其他初始化项或体；未使用的重定向环也拒绝，目标不能是工厂。const 重定向须有 const 目标和潜在常量转发表达式，不放宽嵌套 const 参数资格。

super 形参支持非泛型父类的非重定向生成式构造，含主构造器。位置关联只计 super 形参，命名关联用公共名。类型优先从父形参推断，显式类型须为其子类型，不能靠 dynamic 下转或隐式 call 提取替代。省略默认值时，父默认常量实际类型兼容才继承，否则使用隐式 null 并检查类型。检查转发/显式实参冲突、缺参、位置和 2.17 版本边界。

const 生成式构造支持普通及泛型类，全部字段须 final 且初始化一次，构造无体，父目标也须 const。声明默认值及字段初始化按声明作用域，显式列表检查 potentially constant 资格，不整体视作隐式 const 上下文。实际类、实际类型实参及继承/本类字段决定规范化身份；同类不同构造器可得到同一常量，普通调用仍新建对象。

## 工厂构造器

非泛型类工厂支持块/箭头体、命名/未命名、重定向及 const 工厂。工厂没有 this，不执行所属类字段初始化或隐式分配，可以返回已有对象或子类实例；结果以所属类检查，dynamic 返回有运行时检查。仅有工厂的类仍有字段初始化义务，未调用体也检查。

重定向工厂按类/别名身份解析目标，支持前缀、命名、.new 与私有性。目标签名须是工厂签名子类型，检查循环、禁止的显式默认值、const 资格及抽象生成式目标。实参按原工厂参数上下文求值/检查一次，只转发实际提供的参数，最终目标在自己的作用域补默认值和额外可选参数。super 和生成式 this 重定向不能选工厂。

const 工厂只能重定向到 const 目标；所属类可以抽象或含可变/late 字段，约束施加于最终生成式目标。静态类型来自调用类，规范化身份来自实际类/字段，经别名或重定向不变；可空类别名工厂构造结果非空。

SDK 3.13.7 CFE/analyzer 接受 `factory C([int n]) = D` 到 `D([num n = 4.5])`，虽固定草案还约束目标默认值类型。dartc 跟随 SDK：省略取 4.5，显式仍按 int 检查。泛型类和 external 工厂未支持；3.13 的 factory 简写可用，旧版同名普通方法不因此变工厂。

## 泛型运行时实例

普通、隐式、命名、生成式重定向和主构造器保留实际类实参，推断共用[泛型直接调用](functions.md#泛型直接调用)。形参代入后按源码顺序求值和检查，再分配并初始化。`T` 字段不能因上界允许 null 省略初始化，`T?` 字段可用隐式 null。

字段、非泛型实例方法、访问器、call 和已支持运算符按静态接收者代入，执行时用对象实际类型环境。支持 List、用户类、可空及函数类型嵌套、实参变化的递归构造、同类实际实参的 is/as、类参数协变及非泛型父接口。

由类参数产生的协变检查在成员体前按实际实参检查参数、字段和索引写入；读取不安全协变视图也检查。它不授权收窄覆写，仍需显式或继承 covariant。非泛型闭包能捕获类型环境，const 实例运行时物化保留实参和身份；3.7 起使用调用库的界限推断。

泛型类工厂、late 字段、自身泛型实例方法、方法/构造器提取、泛型父接口、完整 F-bound 和约束求解未支持。默认对象文本不显示具体实参，公开 Type 值和完整模式推断仍缺。

## 构造器函数值

从 2.15 起，非泛型用户类的生成式、工厂和两类重定向可用 `C.new`/`C.named` 提取，支持可选/命名参数、`.call`、括号调用、类型检查及常量容器。普通/可空非泛型别名指向同一构造器，结果类型为非空类。抽象类生成式构造不能提取，工厂可以；构造器不被继承。

构造器引用是常量，无需目标本身为 const，同一构造引用规范化为同一函数对象，不同重定向/工厂声明仍有不同身份。提取 const 构造器后调用仍是**普通函数调用**，不是常量构造。SDK 3.13.7 CFE 跳过未选中分支 `(C.new)()` 的常量错误，dartc 和 analyzer 仍拒绝。常量模式可用 `const (C.new)`，上下文明确时可用 SDK 接受的 `.new` 模式。

生成式值调用在实参之后分配，工厂不隐式分配；重定向工厂只传显式实参，目标补默认值。字段/super 形参先完成关联推断，也适用于主构造器默认值里的前向构造器引用。泛型类、泛型别名、标准库构造器提取仍缺，输出限制同[函数值](functions.md#函数值)。

## 主构造器

从 3.13 起，普通及泛型类支持未命名、命名、const 主构造器，var/final 字段声明参数、普通参数、this/super 形参、默认值、this 初始化列表/体、分号类体和 new/new name 简写。

```dart
class Pair(final int left, final int right) {
  int sum() => left + right;
}
```

省略类型的声明参数先合并父接口字段签名，可写字段两侧须同型；无继承来源时取默认表达式的空上下文静态类型，缺省或 Null 转 Object?。非 late 字段初始化及列表共用参数作用域，禁止包括闭包内的参数赋值；普通参数进入体后可写，已有闭包仍捕获同一绑定。声明字段及 this/super 形参不进入体作用域，late/static 初始化不在参数作用域。

const 主构造的字段表达式按每次实参求值，声明处检查潜在常量资格。检查重复体、额外非重定向生成式构造、重复字段/初始化。协变声明参数须为 `covariant var`，标记归生成字段而非构造形参。泛型父类、assert initializer、mixin、enum 和 extension type 的对应能力仍缺。

## 类修饰符、枚举与元数据

base/interface/final/sealed 及合法 abstract 组合从 3.0 起可用于普通类，sealed 隐含 abstract。跨库限制按实际声明库，别名、导出和 part 不改变归属；base/final 实现禁令及后代修饰要求沿整个父接口图传递。枚举满足后代修饰要求，但本身仍不可被继承/实现。平台库保留规范的旧版 base/interface/final 豁免，sealed 无豁免。

非泛型、无 mixin 的简单/增强枚举支持值、implements、final 字段、const/重定向生成式构造、工厂、静态成员、方法/访问器，以及 values/index/name 和 `枚举名.值名` 文本。生成式构造隐含 const、无体，实例只由自身值创建；拒绝声明 index、values、hashCode。Enum 只允许枚举或抽象类实现。当前 name 是 Enum 接口成员，而 SDK 用 EnumName 扩展提供，所以值名或成员名为 name 的枚举被拒绝；类型参数、mixin、用户 == 和扩展辅助仍缺。

元数据解析覆盖库指令、类/成员、枚举值、函数/变量、形参、类型参数和 record 字段，仅附着紧随其后的声明。CLI 支持常量变量引用、标量、List、null 和已有 const 类构造，按外围作用域、局部遮蔽、前缀及导出过滤绑定；2.14 起显式泛型注解、已有模型的推断和真实 core pragma 的 name/options 常量值可用。其他核心注解及运行时访问仍缺，动态反射明确排除。

## 已知规范与 SDK 差异

- 固定类修饰符规则不要求 2.19 中间类声明后代修饰符，dartc 允许其继承另一库 base 类，现代后代仍受传递限制；SDK 3.13.7 CFE/analyzer 拒绝这个旧版中间类。核心 Exception 为 abstract interface、pragma 为 final，旧平台豁免不适用于现代非法继承。
- 固定字段规则仅允许**无初始化器**的 covariant late final。SDK 3.13.7 接受 `covariant late final int x, y = 1;`，dartc 逐字段检查 setter 并拒绝。
- analyzer 对部分 void 常量、常量属性及局部遮蔽注解未报错，CFE 拒绝；dartc 不据此认为注解有效。SDK 3.13.5 CFE 的多变量局部 const 注解崩溃也不表示语言非法。
- 有限常量构造依赖不因同一构造再次出现就判循环。SDK 3.13.5 CFE 接受按默认值/参数终止的嵌套构造，analyzer 可报递归常量构造；dartc 按实际有限值依赖处理，自依赖仍拒绝，资格检查不执行调用。
