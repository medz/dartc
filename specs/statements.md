bool switch 的确定赋值穷尽性依据 [Dart 3 模式与穷尽性补充规范](https://github.com/dart-lang/language/blob/6a254a68b6ef355ad4559b69dd8ed6893d9f3f3b/accepted/3.0/patterns/feature-specification.md)及跨版本 SDK 行为；旧文件的 case 解释与流规则保持其语言版本语义。
异常的静态规则同时以 SDK 3.13.7 验证；固定草案中省略 on 等价于 dynamic 的描述需结合空安全规则，当前 SDK 的异常参数为 Object。同步展开不提供异步或生成器执行机制。

finally 的静态规则依据[流分析规范](https://github.com/dart-lang/language/blob/6a254a68b6ef355ad4559b69dd8ed6893d9f3f3b/resources/type-system/flow-analysis.md#statements)的 `attachFinally` 与 SDK 3.13.7：入口包含 try 中任意位置抛出时的保守状态，因此 try 内的赋值不保证 finally 内可读。正常结束后可继承 try 或 finally 的确定赋值，清理中可能写入的变量不能保留失效提升。break/continue 的静态目标状态取跳转处的事实，不附加 finally 的赋值；例如 `int x; while (true) { try { break; } finally { x = 1; } } print(x);` 在该 SDK 中仍是静态错误。

## 核心错误与异常对象

依据 SDK [Error](https://api.dart.dev/dart-core/Error-class.html)、[RangeError](https://api.dart.dev/dart-core/RangeError-class.html) 和 [FormatException](https://api.dart.dev/dart-core/FormatException-class.html) API，核心库使用普通 Dart 声明提供 Error、AssertionError、TypeError、ArgumentError、RangeError、IndexError、UnsupportedError、UnimplementedError、StateError、ConcurrentModificationError、Exception、FormatException 和 IntegerDivisionByZeroException 的当前构造与继承关系。对象显式 throw 后沿一般类型关系匹配 catch，实例载荷和 finally 沿已有异常机制处理，编译器不按这些类的拼写接受任意同名声明。

ArgumentError 支持默认、value、notNull 构造及 checkNotNull；RangeError 支持默认、value、range 构造和 checkValueInInterval、checkValidRange、checkNotNegative；IndexError 支持 withLength 与 check。依赖一般动态 `indexable.length` 调用的 IndexError 默认构造、RangeError.index 和 checkValidIndex 仍缺。Exception 是 abstract interface class，跨库限制遵循一般[类修饰符](classes.md)检查；其余未列错误类及完整 Object/Type API 尚缺。

Error.safeToString 不调用用户对象的 toString，字符串保留转义，List 和函数提供安全概要；概要文字不承诺与 SDK VM 的内部类名一致。FormatException 保留 message/source/offset，并输出相应行、位置及有限长度片段。依据 [Error.stackTrace](https://api.dart.dev/dart-core/Error/stackTrace.html) 与 [Error.throwWithStackTrace](https://api.dart.dev/dart-core/Error/throwWithStackTrace.html)，实际 extends Error 对象在首次抛出时填入轨迹，后续 throw、rethrow 或指定轨迹不覆盖该字段；普通重复 throw 的 catch 轨迹仍来自本次抛出。子类 getter 覆写不改变父类存储，implements Error 不自动填充。指定轨迹只比较内容，不承诺 StackTrace 对象身份。已实现类型的转换、布尔条件、空断言、dynamic 空值 throw 和协变写入失败自动抛出 TypeError，并沿同一同步展开路径处理；诊断文本仍缺实际值、目标类型和参数名。非有限数值转整数及非有限浮点整除结果抛出 UnsupportedError，沿同一错误对象与同步展开路径处理；具体边界见[数值 API](expressions.md)。范围、late、整数零除等自动失败尚未统一生成对应错误对象。

声明拥有者为 [core/errors.dart](../lib/src/std/core/errors.dart) 与 [core/exceptions.dart](../lib/src/std/core/exceptions.dart)。行为拥有者为 [values.dart](../test/fixtures/values.dart) 的 `exceptionValues()`、[roots.dart](../test/fixtures/roots.dart) 的 `exceptionRoots()`（异常对象、首次轨迹及其载荷的根），以及 [behavior_test.dart](../test/behavior_test.dart) 的 `failingValues`、`uncaught` 和 `rejected`。首次轨迹填充由 [runtime/exceptions.dart](../lib/src/runtime/exceptions.dart) 实现；自动失败路径继续由相关运行时检查实现和验证。
